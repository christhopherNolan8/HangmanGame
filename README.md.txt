Hangman Game

1. Project Overview
Hangman Game is a word guessing game developed using Python 3.

2. Objectives
The objective is to guess the hidden word by entering letters within a limited number of wrong guesses.

3. Features
- Random word selection.
- Maximum 6 wrong guesses.
- Displays guessed letters.
- Tracks correct and wrong guesses.
- Validates user input.
- Shows win or game-over message.

4. Requirements
- Python 3
- Random module (built-in)

5. Execution Instructions
1. Install Python 3.
2. Open the project folder.
3. Open the terminal.
4. Run the command:

python one.py

6. Input
The player enters one letter at a time.

7. Output
The game displays the word progress, wrong guesses, and the final result (win or game over).
